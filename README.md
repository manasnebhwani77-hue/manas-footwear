# Manas Footwear Catalog

A responsive, static catalog website for Manas Footwear. It uses the supplied brand palette:

- Indigo: `#4533D9`
- Mauve: `#A35E70`
- Warm peach: `#FFC69D`
- Light peach: `#FDC5A0`

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Before publishing

Replace the product information and image URLs with the complete current catalog. The contact links are based on the business details already public on the existing WordPress site.
